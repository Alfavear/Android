# Rexton Launcher

Launcher para la radio Android del SsangYong Rexton W (diseño: barra superior con hora, panel de estado a la derecha, dock de apps abajo).

- Clic largo en un icono del dock: elegir qué app abre.
- Fondo: poner una imagen en `app/src/main/res/drawable-nodpi/bg.jpg` y recompilar.
- Voltaje, combustible y clima quedan en "--" hasta tener lectura del bus CAN de la radio.
- Cambio de aceite: kilometraje manual (cada 5000 km).
