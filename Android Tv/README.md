# Android TV

Proyectos para el onn. 4K Streaming Box (Google TV).

- `launcher/` — launcher estilo PS5 (com.alvear.psl). Requiere una API key de TMDB en `ContentRepo.java` (`KEY`).
- `remote/` — app de mando (com.alvear.tvremote), protocolo Android TV Remote v2.
- `backup/` — lista de paquetes desactivados (reactivables con `pm enable`).
- `PSLauncher.apk`, `ControlTV.apk` — APKs compilados.
